UpDraft board — one-time data import

This page loads seed-data.json (a snapshot of the 108 candidates from the original board) and writes each one into your Firebase project's cards collection. Run this once, right after you've set up Firebase and filled in firebase-config.js — see README.md, section 4.

Safe to run more than once — it overwrites each candidate with the same seed data rather than duplicating anything. You can delete this file (or just stop linking to it) once the import is done.
